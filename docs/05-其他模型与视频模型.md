# 05：其他文本、图片、音频和视频模型

## 重要边界

CC Switch 主要管理 AI CLI 供应商。Codex/Claude Code 的聊天界面不等于“所有多媒体端点的通用客户端”。图片、音频、Embedding、Rerank 和视频建议通过 HrioAPI 在线调试、SDK 或 HTTP 调用。

真实路径和参数以登录后“模型 Contract/完整调用文档”为准。HrioAPI 前端当前声明的常见端点如下。

## 文本与多模态理解

| 协议 | 路径 | 常见用途 |
|---|---|---|
| OpenAI Chat | `/v1/chat/completions` | 文本聊天、视觉理解、多模态消息 |
| OpenAI Responses | `/v1/responses` | Codex/Agent、新式工具调用 |
| Anthropic | `/v1/messages` | Claude Code |
| Gemini | `/v1beta/models/{model}:generateContent` | Gemini 文本/多模态 |

“多模态”不代表一定能生成图片/视频；有些模型只能读取图片或视频并回答文字。

## 图片生成

```bash
curl -X POST "https://hrioapi.hrio.site/api/v1/images/generations" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"IMAGE_MODEL_ID","prompt":"一只白猫坐在窗边，自然光，商业摄影","n":1,"size":"1024x1024","response_format":"url"}'
```

图片编辑模型可能要求 `/v1/images/edits` 和 `multipart/form-data` 上传参考图。

## 视频生成

```bash
curl -X POST "https://hrioapi.hrio.site/api/v1/videos" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d @templates/video-request.json.example
```

常见字段：

| 字段 | 示例 | 说明 |
|---|---|---|
| `model` | `VIDEO_MODEL_ID` | 必须来自模型列表/Contract |
| `prompt` | 中文或英文描述 | 要生成的画面和动作 |
| `seconds` | `5` | 时长；平台可能按秒计费 |
| `aspect_ratio` | `16:9` | 横屏/竖屏 |
| `resolution` | `720p` | 分辨率越高通常越慢、越贵 |
| `image_url` | HTTPS 图片 | 图生视频时可选，必须可访问 |

视频很可能是异步任务：第一次只返回任务 ID、状态 URL 或 operation。此时不要重复创建任务，应查询状态直到成功，再获取 HTTPS 视频结果。

Gemini/Veo 类模型可能使用：

```text
/v1beta/models/{model}:predictLongRunning
```

请求结构是 `instances[] + parameters`，不能直接套用 OpenAI `/v1/videos` JSON。

## 音频

- 语音合成：`POST /v1/audio/speech`
- 音频转写：`POST /v1/audio/transcriptions`
- 音频翻译：`POST /v1/audio/translations`

转写和翻译通常使用 `multipart/form-data` 上传文件；语音合成通常使用 JSON，包含 `model`、`input`、`voice` 和 `response_format`。

## Embedding 与 Rerank

Embedding：

```json
{"model":"EMBEDDING_MODEL_ID","input":"HrioAPI 是统一大模型网关"}
```

端点：`POST /v1/embeddings`。

Rerank：

```json
{
  "model": "RERANK_MODEL_ID",
  "query": "什么是统一大模型网关？",
  "documents": ["统一网关可以用一个 Key 调用多家模型。", "今天天气很好。"],
  "top_n": 1
}
```

端点：`POST /v1/rerank`。

## 成本控制

1. 先用模型列表和 Contract 确认计费单位。
2. 图片先生成 1 张、低分辨率。
3. 视频先 5 秒、720p 或平台最低档。
4. 不要在失败时无限重试；先看 HTTP 状态和任务状态。
5. 给测试 Key 设置额度或到期时间。
