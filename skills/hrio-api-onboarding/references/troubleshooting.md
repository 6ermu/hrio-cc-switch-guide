# 故障排查

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 401 | Key 错误、过期或未启用 | 在 HrioAPI `API Key` 页面重新复制；检查空格和前后引号 |
| 403 | Key 没有模型/端点权限 | 检查账号分组、模型授权和余额 |
| 404/405 | Base URL 或协议路径错误 | 区分 `/api`、`/api/v1` 与完整请求路径 |
| 模型不存在 | 使用了别名或上游模型名 | 以 `GET /v1/models` 返回的 `id` 为准 |
| Codex 报 Responses 错误 | 上游仅支持 Chat Completions | 在 CC Switch 开启本地路由映射并启用 Codex 接管 |
| CC Switch 切换后没变化 | Codex/OpenCode 仍在旧进程中 | 完全退出 CLI 和终端后重新打开 |
| 视频只返回任务 ID | 模型为异步生成 | 查询任务状态，完成后获取 HTTPS 结果 |
| 请求超时 | 模型慢或网络不稳定 | 先用低成本文本模型测试；视频超时应增大到数分钟 |
